# Smart Library Management System

A command-line interface (CLI) Library Management System developed using pure Python without Object-Oriented Programming (OOP) or external library dependencies. State management is handled procedurally through nested dictionary objects and interactive conditional loops.

## Features
- Add new books to catalog with unique IDs.
- Register library members.
- Search books by title or author.
- Issue available books to registered members.
- Return issued books to inventory.
- View formatted listings of all books and registered members.

## Prerequisites
- Python 3.x installed on your system.
- No external `pip` packages required.

## How to Run

1. Clone or download this repository.
2. Open your terminal or command prompt in the project directory.
3. Run the application with:

```bash
python main.py
